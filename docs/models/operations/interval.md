# Interval

* `MINUTE` - Minute
* `HOUR` - Hour
* `DAY` - Day
* `WEEK` - Week
* `MONTH` - Month
* `YEAR` - Year
* `FIVE_MINUTES` - 5 Minutes
* `FIFTEEN_MINUTES` - 15 Minutes

## Example Usage

```go
import (
	"github.com/cloudsmith-io/cloudsmith-go-v2/models/operations"
)

value := operations.IntervalMinute
```
