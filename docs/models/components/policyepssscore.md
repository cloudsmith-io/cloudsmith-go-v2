# PolicyEPSSScore

The EPSS score and percentile of a CVE, and where they came from.


## Fields

| Field                                                                                                               | Type                                                                                                                | Required                                                                                                            | Description                                                                                                         |
| ------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------- |
| `Score`                                                                                                             | `float64`                                                                                                           | :heavy_check_mark:                                                                                                  | The probability of exploitation in the next 30 days, from 0 to 1.                                                   |
| `Percentile`                                                                                                        | `float64`                                                                                                           | :heavy_check_mark:                                                                                                  | The proportion of scored CVEs with the same or a lower score, from 0 to 1.                                          |
| `Modified`                                                                                                          | [time.Time](https://pkg.go.dev/time#Time)                                                                           | :heavy_check_mark:                                                                                                  | The date of the EPSS file that last changed this score or percentile.                                               |
| `ModelVersion`                                                                                                      | `*string`                                                                                                           | :heavy_check_mark:                                                                                                  | The version of the EPSS model behind the latest EPSS file, e.g. v2025.03.14. Null until an EPSS file has named one. |
