# WebOSVSeverity

Extended OSV Severity serializer for frontend consumption.

Reshapes the raw OSV severity entry for display:

- ``label`` — normalized severity label (e.g. "critical", "high")
- ``raw_label`` — original vendor label when it differs from ``label``
  (non-CVSS types only)
- ``cvss`` — present only for CVSS types; contains ``vector``,
  ``base_score``, and parsed metric ``groups``
- ``type`` — severity type string (e.g. "CVSS_V3", "OTHER")

The parent ``score`` and ``numerical_score`` fields are excluded
because they are provided through ``label`` / ``cvss``.
