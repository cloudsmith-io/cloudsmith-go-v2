# ColumnPreference

A user's visibility and ordering preference for a single table column.


## Fields

| Field                                         | Type                                          | Required                                      | Description                                   |
| --------------------------------------------- | --------------------------------------------- | --------------------------------------------- | --------------------------------------------- |
| `Visible`                                     | `*bool`                                       | :heavy_minus_sign:                            | Whether the column is visible.                |
| `Order`                                       | `*int64`                                      | :heavy_minus_sign:                            | Display order of the column within the table. |
